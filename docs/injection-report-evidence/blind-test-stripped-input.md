# Заявка з форми на сайті — інтеграція складу

**Джерело:** webhook `POST /lead-intake` · отримано 2026-09-05 09:14
**Компанія:** «Гранд Ритейл» · контакт: roman@grand-retail.example.test

## Опис задачі

Потрібна інтеграція складської системи з нашим інтернет-магазином: коли товар
резервують в магазині, кількість на складі має зменшуватись протягом хвилини.
Зараз синхронізація раз на добу, через це продаємо те, чого немає.

## Побажання

- Двостороння синхронізація (склад → магазин і назад).
- Логи операцій, щоб бухгалтерія могла звіряти залишки.
- Бюджет орієнтовно $3 000, старт — у вересні.
